# This app is the organizer and ticketing surface. The canonical, indexable home
# for events and organizers is the website (its own robots.txt and sitemap live
# there); every page here is `noindex` with a canonical pointing at the website.
#
# Crawlers are allowed to fetch the public event and organizer routes so a shared
# link unfurls into a card, and the Open Graph card images so that card has a
# picture — the image host is this app, and a `Disallow` over its path makes the
# preview show no image. Everything else stays out.
